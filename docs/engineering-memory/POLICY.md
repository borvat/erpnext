# Minimal engineering continuity

This repository is upstream reference fork. Confirmed fork of frappe/erpnext, large upstream core. Engineering integration should be a small owner-only documentation/instructions overlay on an isolated branch, avoiding copied memory CLI/runtime and upstream code changes.

For a BMAD task, inspect the recorded source in docs/engineering-memory/PROJECT_STATE.md, run git rev-parse HEAD and git status --short, and treat mismatches as stale. Preserve local work. Historical reports grant no approval or current PASS.

At a material task boundary update only a source-bound state summary and append history with exact evidence. Do not duplicate an operational ledger or activate a model/service. Full executable engineering learning is NOT APPLICABLE for this narrow repository role; revisit only if it becomes an owned application development target.
